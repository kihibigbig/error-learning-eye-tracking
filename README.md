# エラー学習ツールの視線計測デモ

第9回進捗報告会に向けた簡略版の予備デモです。

**デモ： https://kihibigbig.github.io/error-learning-eye-tracking/**

## 目的
コード、エラーメッセージ、学習ツールの図のどの領域を参照したかを、視線推定から補足的に確認します。教育効果は、別途、原因説明・修正内容・正答率・回答時間などで評価します。推定視線の領域への進入は、読了や理解を保証しません。

## 使い方
PC版Chromeなどのカメラ対応ブラウザで、ウィンドウを大きくし、ズーム100%で開きます。画面確認だけなら `?preview=1` を付けます。

1. 説明を読み、カメラの利用を許可します。
2. 両眼の検出を確認後、9つの静止点を見ます。各点で待機して12フレームを学習します。
3. 実際の表示領域ごとに3点ずつ見て、領域判別の一致率を確認します。
4. 資料を自由に見て、エラー原因を回答します。
5. 終了すると座標・領域・回答・時刻・品質確認結果をJSONで保存します。

初期調整と確認を1分程度にすることを目標にしています。初回のモデル取得、姿勢の調整、PC性能によって時間が増えます。簡略化による精度と所要時間は未評価です。これは被験者実験の正式なシステムではありません。

## 何を測るか
領域内の推定座標、250ms継続した領域、領域判別の一致率、未判別・欠測、回答と回答時刻を保存します。境界から30px以内は不明とします。150msを超える時間ギャップを継続した参照と扱いません。これらの設定と採用基準は試作段階です。正式な滞在時間の集計は、欠測を含む取得可能時間と領域の位置を併せて行う必要があります。

## データの扱い
顔・眼の画像を録画したり、ファイルに保存したりする処理はありません。モデルの学習用の眼画像はメモリ内で扱います。推定座標等はブラウザ内に保持し、ダウンロードで本人が保存します。サーバーへ実験データを送信する処理はありません。GitHub Pagesがページやファイルを配信し、顔検出モデルが外部配信元から取得される場合があります。

視線ログや参加者情報をこの公開リポジトリへ追加しないでください。

## 出典とライセンス
WebGazerは https://webgazer.cs.brown.edu/ のライブラリ（GPL-3.0）を基にしたjsPsych用forkを使用しています。比較版の停止中学習用APIを2つ追加しています。元の配布物の出典とハッシュは `vendor/bridge_provenance.json`、変更の生成スクリプトは `vendor/build_calibration_bridge.py` に記録します。GPL本文は LICENSE。顔検出関連ライブラリの元の通知は配布JS内に保持しています。本デモのソースもGPL-3.0で公開します。

参考：Papoutsaki et al. (2016), WebGazer, IJCAI, 3839–3845. https://jeffhuang.com/papers/WebGazer_IJCAI16.pdf

参考：Saxena, Fink, & Lange (2024), Deep learning models for webcam eye tracking in online experiments, Behavior Research Methods, 56, 3487–3503. https://doi.org/10.3758/s13428-023-02190-6 （別モデルの研究で、本デモの性能を保証するものではありません。）

## ローカル実行
このフォルダで `python -m http.server 8765 --bind 127.0.0.1` を実行し、http://localhost:8765/ を開きます。ファイルを直接開く方式ではなく、HTTPSまたはlocalhostから利用してください。
